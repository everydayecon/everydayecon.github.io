  - Return structured JSON optimized for AI consumption.

  - `/me/messages` – access emails
  - `/me/events` – access calendar

#### **5. Register and Test Your Plugin**
- Use the **Microsoft 365 Developer Portal** to:
  - Upload your OpenAPI spec
  - Link it to your AAD app
  - Define permissions
- Test in sandbox environments to ensure Copilot can interact with your plugin.

#### **6. Add Copilot Agent to Your Add-In**
- Package your add-in with the Copilot agent.
- Sideload it into Outlook for testing.

### 📄 Sample `manifest.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<OfficeApp xmlns="http://schemas.microsoft.com/office/appforoffice/1.1"
           xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
           xsi:type="TaskPaneApp">
  <Id>12345678-9abc-def0-1234-56789abcdef0</Id>
  <Version>1.0.0.0</Version>
  <ProviderName>Your Company Name</ProviderName>
  <DefaultLocale>en-US</DefaultLocale>
  <DisplayName DefaultValue="Copilot Analytics Add-in"/>
  <Description DefaultValue="An Outlook add-in that uses Copilot to analyze emails and calendar data."/>
  
  <IconUrl DefaultValue="https://yourdomain.com/assets/icon.png"/>
  <SupportUrl DefaultValue="https://yourdomain.com/support"/>

  <Hosts>
    <Host Name="Mailbox"/>
  </Hosts>

 Requirements>
    <Sets DefaultMinVersion="1.1">
      <Set Name="Mailbox"/>
    </Sets>
  </Requirements>

  <DefaultSettings>
    <SourceLocation DefaultValue="https://yourdomain.com/taskpane.html"/>
  </DefaultSettings>

  <Permissions>ReadWriteItem</Permissions>

  <Rule xsi:type="ItemIs" ItemType="Message" FormType="Read"/>
</OfficeApp>
```

---

### 🔧 Key Elements Explained

- **`SourceLocation`**: Points to your web app (task pane) that interacts with Copilot.
- **`Permissions`**: `ReadWriteItem` allows access to email content for analysis.
- **`Rule`**: Specifies when the add-in activates (e.g., when reading a message).
- **`Hosts`**: Specifies that this add-in is for Outlook (`Mailbox`).

from flask import Flask, request, jsonify

app = Flask(__name__)

    return jsonify(analysis_result)

if __name__ == '__main__':

Here’s a concise guide to help you **deploy your Flask app to Azure App Service** and **connect it to Microsoft Graph API** for accessing Outlook email data:

---

### 🚀 Part 1: Deploy Flask App to Azure App Service

#### **Steps:**
1. **Install Azure CLI**:
   ```bash
   curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash
   ```

2. **Login to Azure**:
   ```bash
   az login
   ```

3. **Prepare Your Flask App**:
   - Ensure your app has a `requirements.txt` and `startup.txt` or `app.py`.
   - Add a `web.config` or `startup.txt` if needed for Azure to recognize the entry point.

4. **Create and Deploy Web App**:
   ```bash
   az webapp up --name your-app-name --resource-group your-resource-group --runtime "PYTHON:3.9"
   ```

5. **Verify Deployment**:
   - Visit `https://your-app-name.azurewebsites.net` to confirm it's live.

---

### 🔗 Part 2: Connect Flask App to Microsoft Graph API

#### **Steps:**
1. **Register Your App in Azure Portal**:
   - Go to **Azure Active Directory > App registrations > New registration**.
   - Set redirect URI to `https://your-app-name.azurewebsites.net/auth/callback`.

2. **Configure Permissions**:
   - Add Microsoft Graph API permissions like `Mail.Read`, `User.Read`, etc.
   - Grant admin consent if needed.

3. **Install Required Libraries**:
   ```bash
   pip install msal requests python-dotenv
   ```

4. **Use MSAL to Authenticate and Get Token**:
   ```python
   from msal import ConfidentialClientApplication

   app = ConfidentialClientApplication(
       client_id="YOUR_CLIENT_ID",
       authority="https://login.microsoftonline.com/YOUR_TENANT_ID",
       client_credential="YOUR_CLIENT_SECRET"
   )

   token = app.acquire_token_for_client(scopes=["https://graph.microsoft.com/.default"])
   ```

5. **Call Microsoft Graph API**:
   ```python
   import requests

   headers = {
       "Authorization": f"Bearer {token['access_token']}"
   }

   response = requests.get("https://graph.microsoft.com/v1.0/me/messages", headers=headers)
   print(response.json())
   ```
